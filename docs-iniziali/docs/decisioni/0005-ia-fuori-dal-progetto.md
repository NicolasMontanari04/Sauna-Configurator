# 0005. Funzioni di intelligenza artificiale fuori dal progetto

- **Stato:** Accettata
- **Note:** Sostituisce la predisposizione IA prevista in precedenza

## Contesto
Indicazione del tutor.

## Decisione
Nessuna funzione IA, nessuna estensione pgvector. Le regole di migrabilità lasciano aperta la possibilità di aggiungerla in futuro.

## Motivi
Requisito del tutor; meno complessità nei tempi del tirocinio.

## Alternative considerate
Assistente di configurazione e ricerca semantica (rinviati).
