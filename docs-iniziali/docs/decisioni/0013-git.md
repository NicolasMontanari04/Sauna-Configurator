# 0013. Organizzazione di Git

- **Stato:** Accettata

## Contesto
Due sviluppatori sullo stesso repository.

## Decisione
Repository privato, l'altro sviluppatore è collaboratore; branch separati; nessuna scrittura su main; pull request riviste dall'altro; un file per ogni decisione; prodotti in file separati.

## Motivi
Riduce i conflitti di merge.

## Alternative considerate
Fork separati (più complicati senza vantaggi).
