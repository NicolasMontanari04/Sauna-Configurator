# Mockup del configuratore

`configuratore-saune-mockup.html` è il mockup creato con Claude dai file forniti dall'autore, scaricato dall'artifact "Configuratore saune" il 2026-11-11. Si apre con un doppio clic nel browser, senza server.

È un riferimento per il porting del generatore delle viste (scheda [0016](../../docs-iniziali/docs/decisioni/0016-generatore-famiglie-layout.md)), non codice da usare così com'è:

- i dati sono scritti nel codice; optional e regole di Sky, Air, Aladdin, Yoku S e Cabanon sono di esempio, non vengono dal catalogo (decisione P3);
- carica i font da Google Fonts, che la scheda 0008 esclude;
- ha le viste Esterno, Interno, Pianta e Materiali; le viste scelte ora sono frontale e diagonale (scheda [0021](../../docs-iniziali/docs/decisioni/0021-viste-frontale-diagonale.md)).
